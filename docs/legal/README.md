# Legal pages for Zooofun

Статические документы для сайта и чекбоксов при регистрации.

Русские `.txt` в `ru/` — тексты для юриста и источник формулировок. HTML в корне `docs/legal/` — публичные страницы. После правки `.txt` пересоберите HTML:

```bash
python3 docs/legal/build_pages.py
```

## Публичные URL

База: `https://zooo.fun`.

| Файл | URL |
|------|-----|
| `privacy.html` | `/privacy` |
| `terms.html` | `/terms` |
| `purchases.html` | `/purchases` |
| `children-privacy.html` | `/children-privacy` |
| `support.html` | `/support` |
| `marketing-consent.html` | `/marketing-consent` |
| `consent-user.html` | `/consent-user` |
| `consent-parent.html` | `/consent-parent` |
| `consent-drawing.html` | `/consent-drawing` |

На все публичные HTML подключить `styles.css`. Скрипт `cookie-consent.js` и баннер на сайте показываются сразу. Аналитические cookie включают первую аналитику посещений и Яндекс.Метрику (`METRIKA_ID = 112277307`). На `/play`, `/zoo` и `/island` баннер и счётчик сайта не показываются.

Копии для сайта лежат в `zoofun-web/public/legal/`. После правки `.txt` выполните `python3 docs/legal/build_pages.py` и скопируйте HTML/CSS/JS туда.

## Чекбоксы при регистрации (не объединять)

1. Принимаю [Пользовательское соглашение](/terms) и [Условия покупок](/purchases).
2. Даю согласие на обработку моих персональных данных. [Подробнее](/consent-user).
3. Подтверждаю, что я родитель (законный представитель), и даю согласие на обработку данных ребёнка. [Подробнее](/consent-parent).
4. Даю согласие на обработку рисунка/фото и передачу изображения провайдерам ИИ. [Подробнее](/consent-drawing).
5. *(необязательно, по умолчанию выкл.)* Даю согласие на рекламную рассылку. [Подробнее](/marketing-consent).

Пункты 1–4 обязательны для создания аккаунта. Пункт 5 не блокирует регистрацию.

Покупки — только из аккаунта родителя, не из детского экрана.
